## 2. Механизм «рубцевания» (подтверждение гипотезы пользователя)

Каждое правило — реакция на конкретный убыток, слои накапливались: пилот «2 слота» (ответ на переэкспозицию), требование «АП» (ответ на ложные входы во флэте), «не воскрешать никогда» (ответ на повторные стопы), медблок/BTC/R:R-фильтры. Итог: система непробиваема для убытков — и для прибыли. Проверки выигрываем 75–78%, но рекомендации в основном «ждать».

## 3. Почему не полный возврат

### 4.2 Возвращено из №62–72
- Триггер входа: **«Покупать» 2–3 среза = вход** (не ждать «АП» обязательно); «АП» 1-й срез + цена в зоне = вход.
- Дробные линии: линия = 5% депозита (~$56), допускаются ½ и ¼.
- **Лесенка фиксаций**: тейк-1 = 50% позиции → стоп в безубыток; тейк-2 = 25%; раннер 25% со стопом только вверх.
- **Карантин 3 чистых среза → ре-вход разрешён** (отменяет «не воскрешать никогда» для монет, выбитых по стопу; снятые за дисциплинарный слом тезиса — по-прежнему не воскрешают).

### 4.3 Оставлено из новой эпохи
- Стопы только вверх, никогда не расширяются.
- Правило 13: параболы не догонять (33/33).
- R:R ≥ 2:1 на вход.
- Совокупный риск портфеля **5%** (компромисс между 10% и 1%).
- Правило 8 (флип одного среза ≠ режим), Правило 15 (карантин после убыточного стопа), лестница слома (пересмотр зон).
- Упущенная выгода = ошибка в проверках; >70% = вход (вероятность оценивается по модели: «П» 2–3-й срез в бычьем режиме ≈ >70%).

### 4.3б. Типы ордеров MEXC (добавлено №105, предложение пользователя — принято)

В рекомендациях указывать тип ордера. Схема:
- **Вход, цена НЕ в зоне** → лимитный (верхняя треть зоны). **Цена в зоне** → рыночный.
- **Стоп-лосс** → TP/SL рыночный (гарантия исполнения). **Тейк** → TP/SL лимитный.
- **Стоп+тейк одновременно** → OCO (сработал один — второй отменился).
- **Раннер (25%)** → трейлинг-стоп: BTC/ETH 3–4%, альты 6–8%, параболы 8–10%.
- Шаблон линии $56: вход → OCO на 50% (тейк-1 + стоп) + TP/SL рыночный стоп на 50% → после тейка-1 стоп в безубыток + OCO на 25% (тейк-2) → раннер 25% трейлинг-стоп.
